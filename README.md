# 🐍 Snake Game

A classic Snake game built with **HTML, CSS and JavaScript**, playable directly in your web browser.

This project explores fundamental web development and programming concepts through a simple, interactive arcade game.

## 🎮 Play the Game

**[▶ Play Snake Online](liredro.github.io/snake-game/)**

Use the arrow keys to control the snake, collect food and achieve the highest score possible!

## ✨ Features

- **Classic Snake gameplay** — Navigate the board and collect food to grow
- **Score tracking** — Earn 10 points for every piece of food collected
- **Collision detection** — The game ends if you hit a wall or your own body
- **Random food generation** — Food appears in randomly selected unoccupied squares
- **Restart functionality** — Start a new game at any time
- **Minimalist design** — Dark arcade-inspired interface with green accents

## 🕹️ Controls

| Key | Action |
|---|---|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |

**Objective:** Collect as much food as possible without colliding with the walls or yourself.

## 🛠️ Built With

- **HTML5** — Page structure and Canvas element
- **CSS3** — Styling, layout and responsive design
- **JavaScript** — Game mechanics, keyboard input, collision detection and score tracking

No external libraries or frameworks are required.

## 📁 Project Structure

- `index.html` — Main webpage structure
- `style.css` — Game styling and layout
- `script.js` — Game logic and interactions
- `README.md` — Project documentation

## 🚀 Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to launch the game in your browser.
4. Use the arrow keys to start playing.

No installation is necessary.
